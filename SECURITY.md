# Security and Data Policy

This is a research-code repository for sequential testing in coupled opinion-disease networks.

## Data Policy

Raw real-world network data should not be committed unless redistribution is clearly permitted. Prefer small synthetic demo data or anonymized sample data when examples are needed.

Do not commit:

- Personal data
- Private real-world network datasets
- API keys, passwords, tokens, or credentials
- `.pem`, `.key`, `.crt`, or similar private files
- Machine-specific local configuration

## Reporting Issues

For ordinary bugs, use GitHub Issues.

For sensitive security or data-exposure concerns, contact the repository owner privately instead of opening a public issue.

## Research-Use Disclaimer

This code is for research and educational use. It is not a deployed public-health decision system and should not be used for real-world medical or policy decisions without substantial validation, review, and ethical approval.
