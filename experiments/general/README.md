General-network experiments.

Use this folder for ER, scale-free, Watts-Strogatz, error-sensitivity, and
network-overlap experiments that rely on Monte Carlo approximation.

For the public release, the lightweight topology comparison lives in:

```bash
python examples/general_topology_comparison.py
```

The lightweight non-cooperation demo for physical-test refusals lives in:

```bash
python examples/general_noncooperation_demo.py
```

The original manuscript-scale sweeps used many more particles, graph samples,
and parameter combinations; those are intentionally not run by default.
